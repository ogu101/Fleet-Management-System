<h2>Overview</h2>
A Java-based fleet management system for storing, updating, and managing information about boats. The program supports:

- Loading fleet data from a CSV file or a serialized database file (FleetData.db)

- Adding, removing, and viewing boats in the fleet

- Tracking purchase prices and calculating expenses per boat

- Persisting updated fleet data back to disk for long-term storage
